題材の候補

自分の問いから

日常で気になったこと・不思議に思ったことを、そのまま書くだけ。Claude が「直感とずれる問い」に育てて、案を3つ返します（題名の言い方に使う需要の目安つき）。気に入った問いを「これにする」と、ふつうの候補になります。作るときは「深く調べる」から始まります。

種の泉（世界の科学ニュース）
読み込み中…

世界中（英語・中国語・ドイツ語・フランス語・スペイン語・韓国語・日本語…）の科学ニュースと解説記事を Claude が定期的に読んで、「直感とずれる」問いの種を置きます。気になった種の「この種を育てる」を押すと、問いの案が届きます（上の「自分の問いから」と同じ流れ）。

自動で選んだ題材
読み込み中…

毎朝、海外の動画と日本語の供給を測って、いい題材を自動で選んでここに置きます。数を選んでボタンを押すと、その数だけ追加で探す依頼文がコピーされて Claude が開きます（貼るだけ）。今ある題材は消えません。

候補を手で足す

ひらめき帳

見ていた動画で「これ使える」と思ったら、YouTube の「共有」からこのアプリへ。気づいたことを一言書いて、AI に広げてもらいます。

テーマ検索

いまその題材の動画がいくつあって、どれくらい見られているかを、日本語と海外で比べます。

ポイント帳

動画づくりと声の調整のコツを、自分で読むための所。Claude が記事や動画から拾ったものと、自分で書いたものがたまる。声のポイントは声の調整室にも出ます。（Claude が作業で使う決まりや餌は「工夫」タブ）

自分でポイントを足す

読んだ記事・動画

ここは Claude が作業で使う保管庫（決まりごと・餌・音・工夫）。自分で読むためのコツは「ポイント」タブへ。

Claude への決まりごと

「こういうときは、こうして」という頼み方の決まり。話し合いの中で言った決まりも、Claude がここに足します。決まりが増えても重くならないよう、Claude が3つの段に分けて守ります：部品（部品や道具に入れて、何もしなくても守られる）／機械（数えたり測ったりして点検する）／読む（判断が要るので、当てはまる作業のたびに読む）。足したばかりの決まりは、仕分けるまで毎回読みます。

決まりを足す

餌箱（作り方を育てる）

制作とは関係なく、「この動画（文章）の構成や語りがうまい」と思ったものを餌として入れる。Claude が読んで、構成・肉付け・見せ方・サムネの学びに分けて取り出します。気に入った学びは「決まりにする」で毎回守られ、それ以外も構成や肉付けを考えるときの引き出しとして使われます。

餌をあげる

声の調整室（Mac）

声の型（声そのもの）と読み方を、つまみと一音ずつの高さで調整して、メモを付けて残す所。Mac で VOICEVOX を起動して開く。Claude はここに残した調整を読んで、読み方の決まりを育てます。

声の調整室を開く

音楽の棚

BGM を印象で探して試聴し、保管庫に入れる所。「〇〇な雰囲気の曲が欲しい」と頼むこともできる（スマホ・Chromebook でも使える）。

音楽の棚を開く

音の調整室

動画を流しながら BGM を置き、大きさ・入る所・止める所をその場で聞いて直す所。直しとメモから Claude が BGM の付け方を覚える。

音の調整室を開く

音の保管庫

BGM・効果音・始まりの音をためておく所。動画で使った音は自動でここに残り、次の動画ですぐ使えます。Claude は音を付けるとき、まずここから選びます。自分で見つけた音（自由に使えるもの）も足せます。

音を足す

使い方

制作室は「題材を選ぶ → 作る → 直す → 学ぶ」を、書いてある通りに進めるだけで回すためのアプリです。迷ったら、まず「制作」の画面を開いてください。

まずこれだけ（毎日の流れ）
  1. 朝、スマホに「題材を選んだ」通知が来たら、候補の一番上の「自動で選んだ題材」を見て、作りたいものに「作る」を押す
  2. YouTube を見ていて「これ使える」と思ったら、共有 → 制作室で送って一言書く（ひらめき帳にたまる）
  3. 時間があるときに制作を開き、「次にやること」に書いてある通りに進める
▶ 制作（一本の動画を作る）

「作る」にした題材が並びます。「これを作る」を押すと、11の手順が上から順に出てきます。何本でも並行して作れます：上の「制作中の動画」から押して切り替え、「＋ 新しく作る」から次の題材も始められます。各動画に「Claude が作業中」か「あなたの番」かが出ます。いまやる手順が青い枠で開いています。

  1. 参考と資料を集める：集めたいもの（見せ方の参考・中身の参考・調べた資料・使えそうな素材）に印を付けて数を選び、ボタンを押すと Claude が集めて置きます。足りないものだけ、あとから何度でも追加で頼めます。そのうえで、真似たい場面の録画を選んで送り、ひらめき帳のメモに印を付け、参考にする動画の文字起こしを貼る（量を選ぶと要約される）
  2. 構成を磨く：Claude が骨組み（段ごとに「何を言う・画面で何を見せる・ねらい・秒数」）を出す。段ごとに「残す／差し替え案がほしい／削る」の印や一言の注文を付け、並べ替えや自分での書き換えもして、「次の版にしてもらう」。臨機応変に話したいときは「Claude と話し合う」でチャットへ（決まったことは自動でアプリに反映）。固まったら「決まり」
  3. 肉付けを磨く：決まりにすると自動で頼まれ、段ごとに語り（読み上げる文）と画面の指示が届く。「▶通しで聞く」で読み上げを流し、気になった所でその場で「ここ気になる」。段ごとに「いい／直す／書き直し案がほしい／削る」。磨き方は構成と同じ
  4. 図解を選ぶ：Claude が台本に合う図解の案を見本の画像つきで出すので、気に入ったものだけ選んで作ってもらい、直したい所を書いて直してもらう
  5. 題名：Claude が人を惹きつける題名の案を、ねらいつきで出す。「これにする」で選び、「この方向で別案」で枝分かれさせて磨く。直しの一言は「決まりにする」で貯まる
  6. サムネ：決めた題名に合うサムネを、Claude が見本つきで出す。「これにする」で選び、直しを書いて直してもらう。直しは「決まりにする」で貯まる
  7. 動画を確かめる：仮の動画（声・図解・字幕入りの下書き）を1.5倍速で見て、「2:10 ここをゆっくり」のように一行ずつ書いて「直しを頼む」。時間からどの段の話かが分かり、Claude がその段を直して作り直す
  8. 音：音の調整室で、動画を見ながら BGM を置いて直す
  9. 本番の書き出し：場面の番号なし・高画質（1080p か 1440p）で書き出してもらう。動画はチャットに届く。題名・概要欄・タグ・字幕ファイルもここにそろう
  10. 残して終わる：次からも同じにしたい直しに印 → 工夫の棚に入る

情報を変えて作り直す：制作の画面の上にある枠。一度作ったあとに、資料や素材を足した・決まりごとや餌箱が増えた・長さを変えた、などの変化が自動で並びます。入れたいものに印を付け、「全部作り直す」か「選んだ部分だけ作り直す」かを選んで頼みます。印を付けた所や自分で書き換えた所は守るか選べます。

手順は行き来できます：参考集め・構成・肉付けは、途中で「あ、これもある」となったらいつでも戻って足せます。足した資料や素材は「これを使って直してもらう」で、使ってほしい段を選んで頼むと、Claude が段ごとの変更案を出し、採用したものだけが入ります。構成を変えると、肉付けのずれた段に印が付き、「構成の変化だけ肉付けに反映してもらう」でそこだけ直せます。

やめたいときは「この制作をやめる」、まだ始めていない題材は「制作から外す」で候補にもどせます。終わった手順は、押せば開いて「ここからやり直す」もできます。

頼みごと（ほうっておけば片づく）

同期を設定していると、「要約を頼む」「構成の案を出してもらう」「次の版にしてもらう」「〇個 持ってきてもらう」は、押すだけで頼みごととして記録され、Claude が毎時17分ごろ（7時〜23時）に自動で片づけて、結果をアプリに届けます。チャットに貼る作業は要りません。状況は制作の画面の上の「頼みごとの状況」で見られます。

同期を設定していないときは、今まで通り依頼文がコピーされて Claude が開く形になります。

◎ 候補（題材の一覧）
  • 自動で選んだ題材：毎朝5時41分に、海外の伸びた動画と日本語の供給を測って、Claude が選んで置きます。「作る」「候補に入れる」「いらない」を押すだけ
  • 〇個 持ってきてもらう：数（3・5・10・20）を選んで押すと、その数だけ追加で探す依頼文がコピーされて Claude が開くので、貼るだけ。今ある題材は消えずに増えます
  • 候補を押すと、切り口・日本語の供給・元動画が開きます。★は「作りたい度」。★の多い順に並びます
  • 状態は「候補・作る・保留・作った・捨てる」。「作る」にすると制作の画面に出ます
✎ ひらめき（見ていた動画から気づいたこと）
  • YouTube の共有から送ると、題名と URL が自動で入ります（時間付きの URL なら、何分何秒も入る）
  • 種類は2つ。題材の型（「歌詞の地名を確かめる」のような題材の見つけ方）と、作り方の工夫（見せ方・声・字幕など）
  • 「同じ動画で続けて書く」に印があれば、一本の動画から気づきを続けて書けます。別の動画に移るときは「別の動画にする」
  • 「AI に聞く」を押すと、型を広げる／工夫を整理する質問がコピーされて Claude が開きます
  • 一覧の時間（1:35 など）を押すと、その場面から動画が開きます
⌕ 検索（その題材がどれだけ作られているか）
  • 日本語の言葉で検索すると、上位25本の本数・最多と中央値の再生・10万回超の本数・この1年の本数が出ます。英語・中国語も並べて比べられます
  • 「題名に入っていれば数える言葉」を入れると、関係ない動画を数えません
  • 少ないときは、本当に空いているのか、日本の人が興味を持たないのか、すでに知っているのかを考える（自動選びはこれもやります）
  • 使うには設定で YouTube の API キーが要ります（下の「最初の設定」）
▤ 工夫（編集スタイルと作り方の棚）
  • 編集スタイル：作った動画の型紙（画面の切り替え・地図の動き・字幕・語りのテンポなど）がたまっていく。制作の手順2で「過去のスタイルをそのまま使う」「過去のスタイルと今回の参考を混ぜる」「今回の参考だけで新しく作る」を選べる。届いた型紙は手順3か手順5で残せる。最初から「標準」が入っている
  • 「採用」の工夫は、Claude が動画を作るたびに当てはめます
  • 種類：設定（声や速さなど数字を変えるだけ）、決まり（台本や構成の書き方）、部品（新しい見せ方。作るのに一晩かかる）
  • 一本で目立たせる工夫は一つまで。採用後に効いたかを「効いたか」の欄に書く
▦ 数字（自分のチャンネル）

チャンネル ID（UC から始まる）を入れると、最新50本の再生・高評価・コメントが出ます。API キーが要ります。

Mac で参考動画の場面を録画する
  1. ブラウザで動画を開き、真似たい場面の少し前で止める
  2. Command＋Shift＋5 を押す
  3. 下のバーの左から5番目、右下に●の付いた「录制所选部分」を押す（繁体字なら「錄製選取的部分」）
  4. 出た枠を動画の画面に合わせ、右の「录制」を押して再生
  5. 止めるのは、画面上のメニューバーの■の付いた丸（または Command＋Control＋Esc）
  6. デスクトップに「屏幕录制…」の名前で保存される。それを Claude のチャットにドラッグ

1本の動画から2〜3か所、10〜30秒ずつで十分です。Mac の標準の収録は動画の音を録れません（見た目の分析には困りません）。

最初の設定①　スマホで共有先に出す
  1. Android の Chrome で https://nisenonamae.github.io/seisakushitsu/ を開く
  2. 右上の︙ →「ホーム画面に追加」（「アプリをインストール」と出ることもある）
  3. YouTube で動画の「共有」を押すと、一覧に「制作室」が出る。出ないときは一度スマホのアプリを閉じて開き直す
最初の設定②　YouTube の API キー（検索と数字に必要）
  1. パソコンで Google Cloud のコンソールを開き、新しいプロジェクトを作る
  2. 「API とサービス」→「ライブラリ」で YouTube Data API v3 を探して「有効にする」
  3. 「API とサービス」→「認証情報」→「認証情報を作成」→「API キー」
  4. 出てきたキーを、このアプリの設定の「YouTube の API キー」に貼る（各端末で一度ずつ）

無料で、1日に約30テーマ調べられます。詰まったら画面のスクショを Claude に送ってください。

最初の設定③　同期と自動の頼みごと（いちばん大事）

端末どうしの同期と、ボタン一つで Claude に頼める仕組みは、どちらもこの設定で動きます。データは、ほかのアプリ（行軍表・Anki2 など）と同じ private のリポジトリ notion-daily の中の、制作室用の場所に置きます。

  1. 設定に、持ち主 nisenonamae、リポジトリ名 notion-daily、データのファイル名 roadmap/apps/seisakushitsu/data.json を入れる
  2. トークンは、ほかのアプリ（行軍表・Anki2 など）と同じトークンをそのまま貼る
  3. 「保存して同期」を押し、右上が「同期ずみ」になれば完了
  4. ほかの端末は、設定の「読み取り用のコードを出す」でコードを出し、スマホのカメラで読み取るだけで同じ設定になる
アプリを直したいとき

Claude のチャットで「制作室の〇〇を直して」と頼めば、Claude が直接 GitHub に送ります。1〜2分後にアプリを開き直すと変わっています。変わらないときは、ページを下に引っ張って再読み込みしてください。

困ったとき
  • 「同期できません」と出る：トークンの期限切れか、リポジトリ名の打ち間違い。設定を見直す
  • 検索で「うまく取れませんでした」：API キーの入れ忘れか、1日の上限。翌日にもどる
  • 自動で選んだ題材が出ない：公開ページ（github.io）で開いているか確かめる。手元のファイルを直接開くと出ません
  • データを控えておきたい：設定の「全部のデータをコピー」

設定

Google Cloud で「YouTube Data API v3」を有効にして作ったキー。1回のテーマ検索で約200〜300ユニット（1日10,000まで）。

端末どうしの同期（GitHub）

設定すると、開いたとき・変えたときに自動で GitHub のデータと合わせます。どの端末で何をしたかを気にしなくて大丈夫です。

ほかの端末に設定を渡す

この端末で一度設定すれば、ほかの端末はカメラで読み取るだけで同じ設定になります。トークンを書き留めておく必要はありません（なくしたら作り直せば大丈夫）。

スマホのカメラでこのコードを読み取り、出てきたリンクを開くと設定が入ります。人に見せないでください（このアプリのデータを読み書きできる鍵が入っています）。
