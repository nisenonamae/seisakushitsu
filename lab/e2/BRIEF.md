# E2 の指示書（2026-11-27）：母カバの絵の質を上げる実験（作る係）

担当は1人（作る係）。**触ってよいのは `lab/e2/` の中だけ。** 制作室の実装・`lab/` のほかのフォルダ・設計書は変えない（読むのはよい）。認証トークン・GitHub の API・外部のスクリプトには触らない。

## 目的
P4 の「AI のみ」の母カバより質の高い絵を、**工程を分けて**作れるかを確かめる。大事なのは、見ばえのよい1枚を作ることではなく、**どの工程が質を上げたのか・下げたのかを、あとで見分けられる実験**にすること。評価は、あなたとは別の評価者が、作り方を知らされずに行う（あなたは評価者を呼ばない）。

## 守ること（実験の条件）
- 題材と目標は P4 と同じ：`lab/p4/GOAL.md`（母カバ・横向き・全身・1600×900・背景と色の組・目標 11 項目）
- 絵のデータの形と描き方は P4 と同じ物を使う（`lab/p4/geom.js` の描き方。読みこんで使うか、`lab/e2/` に写す。`lab/p4/` は変えない）。出来た JSON は P4 の画面で開ける形にする。**描き方に新しい機能（切り抜きなど）を足さない**（同じ条件で比べるため。無くて困った所は記録する）
- **最後の工程が終わるまで、`lab/p4/ai/` の絵・`review.md`・`make.js`・`RESULTS.md` の AI の出来の所を見ない・読まない。**（前の絵の反省を知っていたから良くなったのか、工程のおかげかを分けるため。データの形を知るには `lab/p4/geom.js`・`app.js`・`goal.js` を読む）
- 見てよい物：実物の写真（`docs/refs/jitsubutsu/カバ/`）、手本帳の言葉（`docs/refs/tehon.md`）、素材の決まり（`docs/refs/sozai_kimari.md`）、`docs/rebuild/AI_ILLUSTRATION_QUALITY.md`。**他人のイラストはなぞらない・探さない**
- 後ろの工程で、前の工程の形を作り替えない。どうしても直すなら、その工程に戻って作り直し、戻ったことと理由を記録する

## 工程（1つずつ止めて、JSON と画像を残す。`lab/e2/stages/`）
1. **構造・比率の分析**（A）：実物の写真を3枚以上見て、目印（鼻先・鼻の穴・目・耳の付け根・肩・背中のいちばん高い所・腰・しっぽの付け根・腹のいちばん低い所・ひざ・足首・地面）を置き、目印どうしの比を表にする（写真ごとの値と幅）。崩し方（どこを大きく・どこを省くか）を倍率で決める。目印と箱だけの図を画像に。
2. **影絵の下書き**（B）：全体を**1色で塗った形だけ**で、母カバと分かる形を作る。目・口・しわ・色分けは入れない。この段では点が多くてよい。**いちばん大事な工程**：脚・首・鼻づら・耳・しっぽの出入りが、1色でも読めること。直した回ごとに画像を残す（何を見て何を直したか）。
3. **部品に割る**（C）：先に動きの表を書く（歩く・首を振る・口を開ける・耳を振る・しっぽ・まばたき・腹の上下）。回る所（付け根）と、重なり代を決めて割る。部品の表（名前・親・付け根・重ね順）。影絵の輪郭は変えない（割る前と後の影絵の重なりを数字で出す）。
4. **清書**（D）：部品ごとに点を減らし、取っ手を整える。形は変えない（清書の前と後の重なりを数字で出し、ずれた所を画像で）。
5. **配色・影・線の仕上げ**（E）：色の組から。1部品1色・光と影は別の部品・口やしわは線。足した物の一覧。

各工程で残す物：その時点の JSON／仕上がりの画像／**影絵の画像**（全部の部品を同じ暗い色で。地面の影は外す）／点つきの画像／機械の数字（部品の数・点の合計・いちばん多い部品の点・線の部品の数・前の工程の影絵との重なり〔IoU〕）／**その工程で良くなったと思う所・悪くなったと思う所**（自分の見立て。あとで評価者の結果と突き合わせる）。

## 比べるための物（`lab/e2/compare/`）
P4 の AI のみ（`lab/p4/ai/ai_only.json`）と、今回の最後の絵の**両方**に、**同じ道具・同じ決まり**で作る。P4 の JSON を道具に通すのは工程 5 が終わってから（出来た画像も、そこで初めて見てよい）。
- 仕上がりの画像（同じ大きさ・同じ背景）
- 影絵の画像
- 点つきの画像
- 部品をばらして並べた画像（重ね順に、名前つき）
- 関節を回した一覧の画像：頭・4本の脚・耳・しっぽを、付け根で ±15度ほど回した絵を並べる。付け根は、絵のデータにあればそれを、無ければ「部品の囲みの、体につながる側の辺の真ん中」という同じ決まりで両方に当てる（決まりを記録）。すき間（背景が見える画素）の数も出す
- 数字の表（部品の数・点・色の数・線の部品の数・すき間）

## 記録 `lab/e2/RESULTS.md`
①作ったファイル ②工程ごとの成果（画像の名前）と数字 ③工程ごとに、良くなった所・悪くなった所（自分の見立て）④戻った工程があれば、その理由 ⑤描き方に機能が無くて困った所 ⑥P4 の AI のみと並べて見た、自分の正直な見立て（工程 5 のあとに初めて書く）⑦かかった手間（工程ごとの直しの回数）。評価者の結果は、あとで別の人が足す。
