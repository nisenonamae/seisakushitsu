# P1 の使い方（作り手にしてもらうこと）

Mac と Chromebook の両方で、同じことを1回ずつします。1台あたり 3〜5分です。

## してもらうこと

1. **Chrome** で次のページを開く（Mac も Chromebook も Chrome で）。
   `https://nisenonamae.github.io/seisakushitsu/lab/p1/`
2. ページの上のほうにある、紺色のボタン **「① 測りはじめる」** を押す。
3. そのまま **このタブを開いたまま** 待つ（1〜3分。ほかのタブに切りかえない。切りかえると速さが正しく測れません）。
   ボタンの下の白い帯に、いま何をしているかが出ます。途中で絵が動くのは、速さを測っているためです。
4. 白い帯が **「終わりました。…」** に変わったら、**「② 結果のファイルを保存する」** を押す。
   - ダウンロードの所に `p1-result-mac-chrome.zip`（Chromebook なら `p1-result-chromebook-chrome.zip`）ができます。大きさは 数MB〜20MB ほどです（書き出しの側と同じだった絵は入れないので、端末によって変わります）。
5. そのファイルを、**Claude とのチャットに添付して送る**（zip のまま。開かなくてよい）。

これを Mac と Chromebook の両方でして、2つのファイルを送ってください。

## うまくいかないとき

- **② のファイルが大きくて添付できない** → 「（②が送れないとき）数字だけのファイルを保存する」を押して、できた小さいファイル（`….json`）を送る。絵は入りませんが、「書き出しと同じ絵か」は分かります。
- **白い帯に「途中で止まりました：…」と出た** → その文をそのままチャットに書いて送る。
- **表の中に「描けない」と出た** → そのままで大丈夫です（それも結果です）。最後まで進めて ② を押してください。
- 開いたページが古いように見えるとき → ページを読みこみ直す（Mac：Command＋Shift＋R、Chromebook：Ctrl＋Shift＋R）。

## 余裕があれば（しなくてもよい）

- 表の絵を押すと、下の「大きく見る」に本番の大きさで出ます。「⑧ 絵の質（小さな場面）」の R1 と R2 を見比べて、気になった所があれば言葉で教えてください。
- Mac の Safari でも同じことをすると、Chrome 以外でどれだけ違うかが分かります（ファイル名は `p1-result-mac-safari.zip`）。

## 送られてきたファイルの扱い（Claude 向け）

```
python3 lab/p1/compare.py <届いた p1-result-….zip>     # 書き出しの側の絵が無ければ、先に自動で作る（2〜4分）
```
- 出る物：場面ごとの「書き出しの側と同じか・差の数字」、端末の中での差、fps、差を並べた一覧の画像（`/tmp/p1/compare/<名前>/sheet.jpg`）
- 見る順：① R2 CPU が全部「同じ」か（同じなら、CPU の CanvasKit は端末をまたいで同じ絵） ② R1 の差の大きさ ③ fps
- 結果は `RESULTS.md` の「確かめられなかったこと」を消して書き足す

## このページがしないこと
外との通信（GitHub を含む）・保存してある鍵（トークン）の読み書き・外のスクリプトや字の読みこみは、していません。要る物は全部 `lab/p1/` の中にあります。
