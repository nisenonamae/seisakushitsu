# P4「曲線の画面」の使い方（Mac）

## 開く
1. Mac の Chrome で、次を開く：**https://nisenonamae.github.io/seisakushitsu/lab/p4/**
   （手元のファイルで開くなら、`lab/p4/index.html` を Chrome の窓へ引いて落とす。どちらでも同じに動く）
2. 絵は、この Mac のこのブラウザの中に自動で残る（保存ボタンは押さなくてよい）。ほかの端末とは共有しない

## 評価してほしい順番（全部で 40〜60分のつもり）
1. **③ AI のみ を見る**（3分）：上の「③ AI のみ」を押す。見るだけ。拡大（ピンチ）して輪郭を見る
2. **目標を読む**（2分）：上の「目標」を押す。題材は「母カバ（横向き・全身）」
3. **① 人のみ で描く**（20〜30分を目安。途中でやめてよい）：上の「① 人のみ」を押す。空の画面から描く。時間は右上で自動で測っている
4. **② 下組み＋人 で直す**（10〜20分）：上の「② 下組み＋人」を押す。AI が図形で置いた下組みから始まる。直して、足りない物（口・しわ・光・つめ・しっぽ・あご）を足す
5. **見比べる・評価する**：上の黒いボタン「見比べる・評価する」を押す → 3つが並ぶ → 下の表に点（1〜5）とひとことを入れる
6. いちばん下の **「評価.json」を書き出す** を押す → ダウンロードに「評価.json」ができる → **そのファイルを Claude とのチャットに添付して送る**

①と②の順番は、逆でもよい（先に②をやると①が楽になるので、どちらを先にやったかを「そのほか、感じたこと」に書いてもらえると助かる）。

## 描き方（おすすめの流れ：図形から始める）
1. 左の **「円」「四角」「長丸」** を押して、画面の上で引く → 図形が置かれる
   - 四角の丸み・大きさ・回転は、右の「図形の数値」で変える。長丸の太さは、右の「長丸の太さ」
2. 右の **「色」** の四角を押す → 選んだ部品の色が変わる（「塗り」と「線」は、上の切りかえで選ぶ）
3. 形を変えたい図形を選んで、右の **「自由な形に変える」** を押す → 点が出る（左の「点を直す」になる）
   - **点を引く**＝動かす
   - **取っ手（細い線の先の●）を引く**＝曲がり方が変わる。両側がそろって動く。⌥（option）を押しながら引くと片側だけ
   - **線の上を押す**＝点を足す
   - **点を2回続けて押す**＝なめらか⇔角
   - 点を選んで **delete**＝点を消す。右の「取っ手を自動に戻す」＝取っ手を、前後の点から自動で決め直す
4. 口・しわ・光は **「ペン」**：押す＝角の点、押して引く＝なめらかな点。**return** を押すと、開いた線のまま終わる（＝線の部品。太さは右の「線の太さ」）。始点（赤い丸）を押すと閉じて、面になる
   - 右の「押すだけでも、なめらかな点にする」を入れると、押していくだけで、なめらかな曲線になる（マウスでは、こちらが楽なはず）
5. 左右で同じ物（耳・脚など）は、選んで右の **「左右反転の写しを作る」**。同じ物を増やすのは ⌘D（複製）

## よく使う操作
| したいこと | 操作 |
|---|---|
| 取り消し／やり直し | ⌘Z ／ ⇧⌘Z |
| 拡大・縮小 | トラックパッドでピンチ／⌘＋ホイール／下の「−」「＋」。マウスのホイールだけで拡大したいときは、下の「ホイールで拡大」を入れる |
| 画面を動かす | トラックパッドの2本指／スペースを押しながら引く／左の「動かす」 |
| 全体を見る | 下の「全体」（または 0） |
| 選ぶ／点を直す／ペン | V ／ A ／ P（円 O・四角 R・長丸 L） |
| 複数選ぶ | ⇧ を押しながら押す／何もない所から引いて囲む |
| 動かす・大きさ・回す | 「選ぶ」で部品を引く／まわりの□を引く（⇧で縦横の比を保つ）／上の○を引く（⇧で15度ずつ）。矢印キーで1ずつ（⇧で10ずつ） |
| コピー・貼り付け・複製 | ⌘C ・ ⌘V ・ ⌘D |
| 重なり順 | 右の「部品の一覧」の上の「手前へ」「奥へ」（］と［でも） |
| 名前を変える | 一覧の名前を2回続けて押す |
| 隠す・固定 | 一覧の 👁 ・ 🔒 |
| グループ | 2つ以上選んで ⌘G（とくのは ⇧⌘G）。グループの中の1つだけを選ぶのは、⌘ を押しながら押す |
| 点を減らす | 部品を選んで、右の「清書（点を減らす）」。強さを上げると、もっと減る |
| 写真を下敷きにする | 右の「なぞる下敷き」の「画像を選ぶ」（または、画像をコピーして ⌘V）。位置は「下敷きを動かす」を押してから引く。**実物の写真だけ。ほかの人のイラストは置かない** |
| ②で、元の下組みと比べる | 右のいちばん上の「元の下組みを赤い線で重ねる」 |
| ファイルに残す | 右上の「保存・書き出し」→「絵をファイルに書き出す（JSON）」「PNG で書き出す」 |
| 最初からやり直す | 右上の「保存・書き出し」→「この作り方を最初からやり直す」（時間と記録も0に戻る） |

## 気をつける所
- 数字の欄に入れたあとは、**return** を押す（押すと、キーの操作がまた効くようになる）
- 時間は、手が30秒より長く止まった分を数えない。席を外しても大丈夫
- ブラウザの「閲覧データを消す」をすると、絵も消える。心配なら「絵をファイルに書き出す」で残す
