# E4 の記録：動かしたときの質を測る（関節と割り方）（2026-11-28）

担当は1人（Claude）。評価者は呼んでいない。**止まった絵の出来は見ていない。動かしたときだけを見た。**
先に結論を3行で：
- **E2 が P4 より動かしにくく見えた主な理由は、関節の作り（重なり代・付け根）ではなく、影絵の形そのものだった。** つなぎ目のすき間・はみ出しは、E2 でも P4 でも「まわり」の体の 0.1% ほどしか無い。差が出たのは、回したときに輪郭に出来る細いへこみ・とがり（E2 0.41% ／ P4 0.06%）。E2 は脚のあいだのアーチ・胸の角・あごの下など、輪郭に細かい形が多く、部品が動くとそこに段が出来る。P4 は脚が角丸の四角・胴が大きな丸で、動いても段が出来にくい。
- **重なり代を深くするだけ（E2 v2 のやり方）は、効かないどころか、はみ出しを増やした**（平均 0.04% → 0.22%。しっぽは 14度、頭は 8度から見え始める）。深くした分の角が、回すと親の外へ出る。
- **効いたのは「丸く受ける＋付け根を、玉が影絵の中に入りきる所へ置く」（版6）**。すき間・はみ出しは 8 関節・10 角度のどれでも 0.2% 以下（45度まで）。ただし形（へこみ・とがり）は良くならず、切り抜きが無いせいで、体の中に下の色（腹のピンク）が筋になって見える所が新しく出来た。

## ② 測り方と、前の測り方（E2 の `joints.py`）との違い
回す角度：±5・±10・±15・±25・±35度（全部の数字）と、1度きざみで 45度まで（壊れ始める角度）。＋は画面で時計回り（頭なら鼻が上がる。脚なら足先が前＝左へ）。

**物差し（部品ごとに決める。割り方を変えても変えない）**
- **w＝部品の幅**：回す部品（いっしょに回る物も入れた影絵）に入る、いちばん大きい円の直径。頭 258・前脚 148／98・後ろ脚 170／122・耳 44／28・しっぽ 31。
- **玉**＝付け根を中心に半径 w/2 の円。**まわり**＝付け根を中心に半径 w の円（指示書の「部品の幅ほどの円」）。
- 割り方を変えた版は、元の版（版1）の w と面積を引き継ぐ（重なり代を深くすると部品が大きくなり、物差しが変わってしまうのを防ぐ。**前の測り方の失敗はここ**：円の半径を「部品の囲みの長い辺 × 0.35」にしていたので、v2 は円が広がった）。

**数える物と、分け方の決まり**
| 数字 | 決まり |
|---|---|
| **すき間（意図しない）** | 回す前は体だったのに背景になった画素のうち、**玉の中**にある物。理由：円は回しても同じ形なので、付け根のすぐまわりの体は、回しても消えないはず。消えたら、つなぎ目が開いたか、付け根が輪郭に近すぎる |
| **はみ出し（意図しない）** | 回す前は背景だったのに体になった画素のうち、**もとが重なり代**（回す前に親の影絵の中に隠れていた所）だった物。例：脚の上の端が背中から出る・頭の後ろが胴の外へ出る・しっぽの根が尻から出る |
| 意図した動き | それ以外の、消えた・増えた画素（脚の先が動いた、など。一覧では水色・緑） |
| 割合 | ①部品の面積に対して（`gap_part`・`poke_part`）②「まわり」の中の体の面積に対して（`gap_disc`・`poke_disc_r`。表はこちら） |
| **形（へこみ＋とがり）** | 「まわり」の中で、太さ 0.2w までの細いへこみ（影絵をふくらませて ちぢめると埋まる所）と、細いとがり（ちぢめて ふくらませると消える所）が、回す前より増えた面積。つなぎ目に出来る段・切れこみ・角の出っぱりが入る |
| **新しい折れ** | 「まわり」の中の輪郭で、長さ 0.12w の弦2本のなす角が 25度以上の山を拾い、回す前の折れ（同じ場所・部品といっしょに回った場所・0.6w までにすべった場所）で説明できない分の角度を足す |
| **重なり** | 回す部品と親の重なりに入る、いちばん大きい円の直径 ÷ w（回す前 `overlap0`・回したあと `overlap`）。0 になれば離れる |
| 影絵の変化 | 回す前と後の IoU（`iou`）と、「まわり」の中だけの差（`xor_disc`）。意図した動きも入る |
| **壊れ始める角度** | 面＝（すき間＋はみ出し）÷「まわり」の体 が 0.5%（見え始め）・2%（はっきり）を超える最初の角度。形＝0.5% を超えて3度つづく最初の角度。折れ＝40度を超えて3度つづく最初の角度 |
| 体の中の色（`inner.py`） | 玉の中で、回す前も後も体である画素のうち、色が変わった割合。影絵では見えない、下の色の筋・線のずれ |

縁のにじみを数えないよう、太さ 3 画素（絵の倍率に比例）より細い物は、すき間・はみ出しに入れない。
試してやめた決まり：「回す前の姿でも、絵ごと回した姿でも体なのに、関節で回すと背景になる画素＝すき間」。脚を振ったときの、わきの下の三角（つなぎ目は開いていないのに、ふつうに出来る空き）を、すき間と数えてしまった。

**前の測り方との違い**：①円の大きさを部品の幅で決め、版が変わっても同じにした ②すき間・はみ出しを「意図した動き」と分けた（前は、円の中で消えた・増えた画素を全部数えていた） ③割合で出した ④「細い割れ」の太さを 10 画素の決め打ちから、w に比例に ⑤角度を5つ＋1度きざみに ⑥つながった関節（首 → 頭）も測れる。

**物差しが大きさで変わらないか**（`out/大きさの確かめ.md`。版1を絵ごと 0.5・1・1.5 倍にして測った）
- **変わらなかった**：すき間・はみ出し・IoU・まわりの差（どの関節でも、差は 0.3 ポイントまで）。形は、w が 98 以上の関節（頭・脚4本）では 0.15〜0.51% の中で、差は 0.09 ポイントまで。
- **変わった（信じすぎない）**：w が 45 以下の小さい部品（耳・しっぽ）の「形」は、0.45〜1.28% とぶれた（細さの物差しが 3〜4 画素になり、画素の丸めが効く）。**「新しい折れ」は、頭で 51 → 118度（1.5倍）と跳ねた**。折れは、角度を1度変えるだけでも 0 になったり 100 になったりする。**折れの数字は、版の順位を決めるのには使えない**（表には出したが、下の見立てには使っていない）。

## ④ 何が効いたか・効かなかったか
| 変え方 | すき間・はみ出し | 形（段・とがり） | 見立て |
|---|---|---|---|
| **重なり代を深く**（版2） | **悪くなった**。はみ出しの平均 0.04 → 0.22%。頭 −8度・しっぽ ＋14度から見える（版1は −16・＋32） | 変わらない | **効かない。** 版1は、もともとつなぎ目が開いていない（重なり 0.70w）。足りていない物を足したのではなく、角のある重なり代を長くしたので、回すとその角が親の輪郭の外へ出た。E2 v2 で評価者が「脚の上を伸ばしたのは悪くなった」としたのと同じ向き |
| **割る場所**：首の部品をはさむ（版3） | 悪くなった。頭 −6度から見える・−32度で 2% | 頭の形は少し良い（0.27 → 0.19） | 動きが2つの付け根に分かれるので、輪郭の変わり方はなだらかになるが、部品が1つ増え、その角が出る。首の部品の形を丸く作らないと得にならない（今回は、重なりを 40 ふくらませただけの形）。**半々** |

## ⑤ 静止画の出来との関係
- **止まった絵を悪くした版は無い。** 影絵の重なり（IoU）は、版1に対してどれも 0.9996 以上、色が変わった画素は 0〜80（1600×900 の中。縁のにじみ）。`out/止まった絵.png`・`.json`。版5・5x は付け根だけなので、絵は1画素も変わらない。
- ただし、**止まった絵が同じでも、絵のデータは悪くなっている**：形の足し引きを折れ線でやったので、点が 152 → 499〜981、部品が 28 → 31〜38。人が直せるデータではない（清書していない）。関節の形を比べるための物で、採る物ではない。
- 動かしたとき、止まった絵では隠れていた傷が出る版がある：版4・6 は、手前の脚の付け根に腹のピンクの筋、頭の首の上に細いとげ（③）。
- 止まった絵の良さ（影絵の読みやすさ）と、動かしたときの形の崩れは、今回は逆向きだった（④のまとめ）。E2 v2 で背中をふくらませたような、影絵そのものの直しは、今回は測っていない。

## ⑥ 描き方・データの形に無くて困った物
- **切り抜き（ある部品を、別の部品の形で切る）が無い**：いちばん困った。丸い付け根を上の部品に持たせると、下にある別の色（腹のピンク・首の影・背中の光）を隠してしまう。そこで、丸い付け根を「親と同じ色の別の部品」にして、親のすぐ上・飾りの下に入れた（親と同じ色のときしか使えない手）。その結果、脚を回すと、飾り（腹のピンク）が脚の付け根の上に筋になって残る。切り抜きがあれば、「腹のピンクは胴の形で切る」「脚の付け根は胴の中だけ見せない」と書けて、筋もとげも出ない
- **重ね順が1本しか無い**：下に重なる部品（奥の脚・しっぽ・奥の耳）には、受ける側を広げる「受け」を足せなかった（足すと、止まった絵で奥の脚を隠す）。「この部品は、親の下だが、親の受けよりは上」のような、関節ごとの重ね順が要る
- **付け根・親子・いっしょに回る物**：E2 は `pivot`・`rigParent`・`follow` を勝手な項目として持っていた（使えた）。P4 には無いので、決まりで置いた。**付け根は、決まりを1つ変えるだけで結果が大きく変わる**（P4 の後ろ脚（手前）は、囲みの決まりだと「ももの線」まで囲みに入り、付け根が (1127,596) という脚の外になる）。付け根は、絵のデータが必ず持つべき
- **関節の「幅」と「玉」をデータが持っていない**：測るたびに影絵から出した。リグに「付け根・玉の半径・回してよい角度の幅」を持たせれば、点検は速く、決まりもぶれない
- **形の足し引き（合わせる・引く・重なり）が無い**：shapely でやり、折れ線で戻した。曲線のまま足し引きできないので、点が数百に増えた
- **つながった関節**（首 → 頭）は、道具の側で親子の行列を掛けて描いた。絵のデータに親子の回転を持つ場所は無い

## ⑦ 限界
- **回すだけ。** 曲げる・伸ばす・点を動かす（口・腹）・差し替え・2つ以上の関節を同時に動かす（歩く）は見ていない。脚を前後に振ったとき、となりの脚と重なる・離れる、は「意図した動き」に入れている
- **影絵（1色）で測っている。** 体の中の色の変化は、`inner.py` で玉の中だけを粗く数えただけ。重ね順のおかしさ（奥の脚が手前に出る、など）は数えていない
- **「意図した／しない」の分け方は、こちらが決めた決まり**で、人の目と合うかは確かめていない（評価者を呼んでいない）。とくに、すき間を「玉の中」に限ったので、玉より外に出来る切れこみは「形」にしか入らない。0.5%・2% という線も、こちらで引いた
- **「新しい折れ」は当てにならない**（②）。小さい部品（w が 45 以下）の「形」もぶれる
- つながった関節（版3の首）は、玉・まわりを、回す前の付け根の場所に置いたまま測っている（子の付け根は、親が回ると動く）
- 版は、決まりで機械的に作った1通りずつ。首の部品・丸い付け根の形を、人が手で良く作れば、結果は変わりうる。E2 v2 の実物（背中の形も変えた版）は測っていない
- 絵は母カバ1つと、P4 のカバ1つだけ。ほかの題材で同じになるかは未確認

## ⑧ 設計（AI_ILLUSTRATION_QUALITY.md 7節）への提案
1. **3 の「重なり代を付ける：付け根の向こうへ丸く伸ばす」を、数字の決まりにする**：「回る側の端は、付け根を中心にした円にする。円の半径は、つなぎ目の半分（h）以上。その円が、影絵の中に入りきる所に付け根を置く（入りきる中で、深い方）。**角のある重なり代を、深く伸ばさない**」。深さではなく、**円が入るかどうか**が決め手（版2 対 版5・6）
2. **割る前に、影絵の段で「関節の玉が入るか」を点検する**（工程 2 と 3 のあいだ）：動きの表の付け根ごとに、半径 h の円を影絵に置いてみる。入らない所（今回は、頭・手前の耳・しっぽ）は、影絵を直すか、動きの幅を狭める。**動かしやすさは、割り方より前に、影絵で決まっている**
3. **「機械の点検」の数え方を、この道具の形に**：すき間・はみ出しを「意図した動き」と分ける／部品の幅 w にそろえた割合で出す／角度を1つではなく、壊れ始める角度で出す／形（へこみ・とがり）を別に出す。合格の線の案：動きの表の角度の幅で、すき間＋はみ出しが「まわり」の 0.5% 未満。形の線は、人の目と合わせてから決める（未確認）
4. **影絵を決めるとき、動かす部品のまわりの輪郭を単純にする**（7節か、4節の影絵の所へ）：脚の根元を丸く・となりの部品とのあいだを細い切れこみにしない・付け根の近くに角を置かない。読みやすさ（細かい形）とぶつかるので、「動く所は単純に、動かない所で形を語る」と分けるのが案
5. **新しい仕組みに要る物に足す**：切り抜き（部品を別の部品の形で切る）／関節ごとの重ね順（受け）／リグに付け根・玉の半径・角度の幅。これが無いと、丸い関節は「親と同じ色のときだけ」になり、下の飾りが筋になって見える（⑥）
6. 「部品の数が、動きの表から数えた数より多ければ、割りすぎ」はそのままでよい。首の部品をはさむ（版3）は、部品を増やしたわりに得が無かった
