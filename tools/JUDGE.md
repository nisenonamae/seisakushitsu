# 選ぶ役の手順（2案を並べて選ぶ）

あなたは「選ぶ役」。作った本人でも、見る役でもない。同じ場面・同じ秒の2つの版（左・右）を見て、**どちらが良いか**を選ぶ。どちらが新しい版かは知らされない（知ろうとしない）。

## 渡される物（1つのフォルダ）
- `brief.md`：今回の段・ちがう1か所・手本帳のやり方・作り手の好み（T）
- `<場面>_左右.png`：3つの秒。どの段も左と右
- `<場面>_実物.png`（あれば）・`調べた記録.md`

## 選び方（この順で比べる）
1. **乱れがないか**：形がくずれている・部品が浮いている・頭が2つに見える、などがある方は負け（指摘帳 B）
2. **事実に合うか**：調べた記録・実物に合う方
3. **自然に見えるか**：実物を知っている人が見て、違和感が少ない方
4. **手本に近いか**：手本帳のやり方ができている方
5. 作り手の好み（T）に合う方
- 上で差がついたら、下は見ない。全部同じくらいなら「同じ」

## 返す形（これだけ）
```
答え：左 か 右 か 同じ
決め手：（上の1〜5のどれで、何がちがったか。1行）
新しい乱れ：（選んだ方にもある乱れ。なければ「なし」）
```
