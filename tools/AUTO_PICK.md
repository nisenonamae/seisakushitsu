# 題材の自動選び（Claude が実行する手順）

この手順は、毎朝の自動実行と、アプリの「今すぐ選んでもらう」の両方で使う。
結果は `data/auto.json` に書き、commit して push する（制作室アプリがこのファイルを読む）。

## 決まりごと
- `nisenonamae/notion-daily` が用意できるときは、`roadmap/apps/seisakushitsu/data.json` の `rules[]` のうち `active` が true で `scope` が「全部」か「題材探し」のものを読み、下の方針より優先して守る（読むだけ。このファイル以外は触らない）

## チャンネルの方針（題材の条件）
- 「地図・映像で解く、なぜ／もしも」のチャンネル。アニメーションで見せられる題材がよい
- **日本の人にとって初耳**であること。日本の人が日常で知っていること（日本の電気の50Hz/60Hz など）は伸びにくいので外す。「海外が首をかしげる日本のこと」も原則外す
- 狙い目は「海外では常識・定番だが、日本ではほぼ扱われていないなぜ」「データで動かせるもしも」
- 外すもの：政治・選挙・戦争の時事、宗教や民族の対立、健康・お金・法律の助言、特定の人物の評価、歌詞や作品の中身の書き写しが必要なもの
- 専門知識がほとんどいらず、公的な資料や公開データで確かめられるもの
- 作り手が興味を持ちやすい分野：地図・地理の謎、仕組みの雑学、シミュレーション・もしも、合戦（ただし架空や、調べものが軽いもの）

## 手順
1. `python3 tools/harvest.py` を実行する（海外の発信元の最新動画から、チャンネル内で特に伸びた動画を `tools/out/raw.json` に集める）。
   発信元は `tools/channels.json`。足りない言語圏（スペイン語・韓国語・ロシア語など）の良い発信元を見つけたら追加してよい
2. raw.json の上位（ratio が高いもの、再生が大きいもの）から、方針に合う「問い」を 15 個ほど選ぶ。題名をそのまま訳すのではなく、日本の人向けの問いに言い直す。
   短い動画（shorts）の問いも、10分の動画の種として使ってよい
3. それぞれ、日本語の供給を測る：`python3 tools/jpsupply.py "日本語の検索の言葉" "題名に入っていれば数える言葉,…"`
   - 検索の言葉は 2 通り試す（言い方を変える）。英語の動画の自動翻訳の題名は数えない（jpsupply はかなを含む題名だけ数える）
4. **日本で少ない理由を見立てる**（少ない＝空き、と決めつけない）
   - 作られていない（本当の空き）／作られたが届いていない／日本の人が興味を持たない／日本の人がすでに知っている／測り方の誤り
   - 手がかり：隣の題材（同じ興味の人向けの日本で作られた動画）の伸び、既存動画のチャンネル規模、日本の暮らしとの接点
5. 点数（各 1〜5）：海外の需要×3、日本の空き×3、初耳度×2、地図・アニメ映え×2、調べやすさ×1、鮮度×1。満点は 60
6. 点数の高い順に **5〜8 個** を `data/auto.json` に書く。すでに `data/auto.json` にある問い（`items` と `history`）と同じものは入れない
7. commit（メッセージ例「題材の自動選び 2026-11-15」）して push する

## 数を指定されたとき（アプリの「〇個 持ってきてもらう」）
- 手順は同じ。ただし選ぶ数は指定どおり（足りなければ raw.json のさらに下や、channels.json に発信元を足して探す）
- `items` は置き換えず、**今ある items の後ろに追加**する。`updated` は今日の日付にする
- 今ある `items` と `history` にある問いは選ばない。追加した問いは history にも足す
- 数が多いとき（10個以上）は、問いごとの日本語の供給は検索の言葉を1通りで測ってよい

## data/auto.json の形
```json
{
  "updated": "2026-11-15",
  "items": [
    {
      "id": "a20261115-1",
      "q": "日本の人向けの問い",
      "pillar": "土地 / 暮らし / もしも / 仕組み",
      "angle": "日本の切り口、地図・アニメで見せるもの（一文か二文）",
      "demand": "海外の需要（例：英語・Practical Engineering で約510万回）",
      "supply": "日本語の供給（例：同じ問いの日本語動画は1本、最多 約4万回）",
      "cause": "日本で少ない理由の見立て（一文）",
      "score": 48,
      "why": "この題材を推す一番の理由（一文）",
      "links": [{"src": "EN Practical Engineering", "title": "元動画の題名", "views": 5100000, "url": "https://..."}]
    }
  ],
  "history": ["これまでに出した問い（重複を避けるため。新しい items の q をここに足す。200個まで）"]
}
```
- 毎朝の自動実行では `items` を置き換える（前回の items の q は history に移す）。数を指定されたときは追加する
- 数字は測った値だけを書く。推測の数字は書かない
