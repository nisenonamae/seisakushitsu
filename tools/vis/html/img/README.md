- `nl_below.png`（海面より低い所）・`nl_flood.png`（洪水から守られている所＝海面より上だが洪水の恐れがある所）：経度 3.2〜7.3・緯度 50.7〜53.6 を 820×870 に並べた白い型（透明＝当たらない）。元は Wikimedia Commons「The Netherlands below sealevel and protected from floods.png」（Reboelje、CC BY-SA 3.0）を、都市の位置で合わせて塗り分けを読み取ったもの。**使った動画には「Reboelje（CC BY-SA 3.0）」の表記が要る**。オランダの陸（州の形−湖）に重ねると、低い所が約27%、合わせて約6割（オランダ環境評価庁の 26%・59% とほぼ合う）
