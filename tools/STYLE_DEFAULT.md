# 標準の型紙（参考の録画がないときに使う）

録画から型紙を作れたら、そちらを優先する。採用された工夫（アプリの工夫の棚で「採用」のもの）があれば、それも当てはめる。

## 全体
- 長さ 9〜11分。一人の語り手（落ち着いた声）＋地図が主役
- 冒頭15秒で「問い」と「答えの気配」（地図の一番の変化を一瞬だけ見せる）。挨拶やチャンネル紹介はしない
- 構成：問い → ふつうの答え → 本当の答え → 意外な広がり → 結び（最後にひっくり返しがあれば置く）

## 画面
- 画面が変わる間隔：平均 4〜6 秒。説明が込み入る所ほど長く、山場の手前は短く刻む
- 地図：落ち着いた色（海は青灰、陸は明るい砂色）、注目する所だけ強い色。寄るときはゆっくり（2〜3秒）
- 文字：画面に出す文字は短い名詞か数字だけ。語りをそのまま字幕にするのは下の帯で
- 一本に一つ、その題材でしか成り立たない見せ場を作る

## 語り
- 1分あたり 300〜330 字くらい。文は短く、数字は一場面に一つ
- 問いかけ → 間（0.5〜1秒）→ 答え
