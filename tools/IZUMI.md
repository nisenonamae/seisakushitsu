# 種の泉（世界の科学ニュースから、問いの種を集める）

作り手の頼み（2026-11-22）：「世界中の科学ニュースを見漁って教えてくれるようにしてほしい」。
自分の問いの回（kurzgesagt のように、ありふれた疑問を深く調べて化けさせる）の**種**を、世界の科学ニュースから集めて、制作室の候補の画面「種の泉」に並べる。
作り手が「この種を育てる」を押すと、`seed_grow`（問いに育てる）→ 制作の `research`（深く調べる）へ進む。

結果は**アプリのリポジトリ**の `data/izumi.json` に書き、commit して push する（制作室が読む）。データのリポジトリ（notion-daily）は触らない。

## どこを見るか（世界中・いろいろな言語）
WebSearch と WebFetch で読む（シェルからはサイトに届かない）。毎回ぜんぶは見なくてよいが、**英語だけに偏らない**（毎回、英語以外を2つ以上）。

| 言語 | 出どころ |
|---|---|
| 英語 | EurekAlert!、ScienceDaily、Phys.org（大学・研究所の発表が集まる）／Quanta Magazine、Knowable Magazine、The Conversation（研究者が書く）、Smithsonian Magazine、Atlas Obscura（科学寄りの記事） |
| 日本語 | 大学・研究機関のプレスリリース、JST サイエンスポータル |
| 中国語 | 科学网（sciencenet.cn）、中国科学院の発表、果壳 |
| ドイツ語 | idw（大学の発表）、Spektrum.de |
| フランス語 | CNRS Le journal、Futura Sciences |
| スペイン語 | SINC（agenciasinc.es） |
| 韓国語 | 동아사이언스（dongascience.com） |

足りない地域（インド・アラビア語圏・ロシア語・ポルトガル語など）の良い出どころを見つけたら、この表に足してよい。

## 2種類の種
- **新発見**：ここ2〜3週間の研究の発表。「〜だと思われていたが、実は〜」
- **定番の不思議**：日付は古くてもよい、解説記事にある「言われてみれば不思議」（例：木の根元に穴がないのはなぜ）。kurzgesagt の題材の多くはこちら
毎回、両方を混ぜる（だいたい半々）。

## 選ぶ条件（チャンネルの方針）
- **見る人の直感とずれる**こと（`gap` が一文で書けないものは選ばない）
- 専門知識なしで、地図・図解・アニメで見せられる。10分の動画の芯になる広がりがある
- 分野は自由（生き物・地球・宇宙・物理・技術・暮らしの仕組み・地理・歴史の科学など）。ただし **時事政治・医療健康（病気・薬・健康法）は扱わない**。歴史・人どうしの争い・事故は、客観的に扱えるなら可
- 一つの研究だけの、まだ再現されていない派手な主張は `sure` を「要確認」にする。うさんくさいもの（擬似科学・出どころ不明）は入れない
- `history` にある種と同じものは入れない

## 書き方
- 記事の文を写さない。自分の言葉で短く（著作権）
- 元の論文が分かれば `paper` に。無料で読めるか（PubMed Central・arXiv・bioRxiv・出版社の無料公開など）を `free` に。分からなければ書かない
- 日付・数字は記事のとおり。確かめていないものは「要確認」

## data/izumi.json の形
```json
{
  "updated": "2026-11-22",
  "items": [
    {
      "id": "i20261122-1",
      "kind": "新発見 / 定番の不思議",
      "seed": "問いの種（日本語。作り手が読んで一瞬で分かる、素朴な疑問の形）",
      "find": "何が分かったか・何が不思議か（一〜二文）",
      "gap": "見る人の直感と、実際とのずれ（一文）",
      "why": "動画になりそうな理由（地図・図解でどう見せられるか、どこへ広がるか。一文）",
      "field": "生き物 / 地球 / 宇宙 / 物理 / 技術 / 暮らし / 地理 など",
      "wow": 3,
      "sure": "確か / たぶん / 要確認",
      "src": {"outlet": "出どころの名前", "lang": "英語", "title": "記事の題名", "url": "https://...", "date": "2026-11-18"},
      "paper": {"title": "論文の題名", "url": "https://...", "free": true}
    }
  ],
  "history": ["これまでに出した seed（重複を避けるため。200個まで）"]
}
```
- `items` は**後ろに足す**（作り手がまだ見ていない種を消さない）。ただし 60 件を超えたら古い順に消す。足した seed は `history` にも足す
- 1回に足すのは **8〜12 件**。`wow`（驚き度 1〜3）が 3 のものを最低 3 件
- `updated` は今日の日付

## 終わったら
commit（メッセージ例「種の泉 2026-11-22」）して push。報告は、足した種を驚き度の高い順に一行ずつ（種・出どころの国/言語）。
