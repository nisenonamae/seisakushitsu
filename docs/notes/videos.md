- 立体のアリ・5回目（作り手「足りないのはディテール。お手本の手法は『一本線』と『部分色分け』とその組み合わせ。顔に部分的に上塗りして影にし、一本線で補う。歯が分かりやすい」）：頭・胸・腹に上塗りの面（明るい面・暗い面・ほお）と短い一本線を足し、あごは太い線＋中の細い明るい線に、すねは少し暗い色にした。部品（plate の deco：zone と dash）として入れたので、ほかの絵でも使える

### 絵の練習：図形にしない頭（6回目・2026-11-21）
- 作り手の直し「顔も体もどこか円形。図形にしない」。原因は、部品を全部「だ円の板」で作っていたこと（回せる代わりに形を捨てていた）
- `ant.html` の `mode:'head'`（`antHead`・`blob`・`HK`）：輪郭を12個の点で描き、点ごとに角の丸みを持たせる。横・ななめ・正面の輪郭を別々に用意し、間は点を混ぜる。明るい面・暗い面は、輪郭をずらした形で作る
- 頭だけの試し。作り手の評価待ち。通れば胸・腹に広げ、ant5 の頭と入れ替える
- 7回目（作り手「正面はいい。ななめ・横は本当にこの形？」）：横は「くさび」（後ろが厚く口先へ細い・上と下はほぼまっすぐ）。ななめは顔の面と横の面を色で分ける（`sp`。面の境目が頭の角になる）。あごは輪にせず、先を開いた2本に。**決まり：向きごとの輪郭を描く前に「どの面が見えるか」を言葉にし、面ごとに色を分ける**
- 8回目（作り手「一本線は太くていい。ゆるキャラすぎず、少しかわいく、リアルで、不快でない塩梅。一覧に並んでもおかしくない顔を」）：`ant.html` の `mode:'faces'`（`antFace`・`FACES`）。**決まり：線は太く（触角・あごは目と同じくらい）／目は実物より大きく2色だけ・白い光と瞳は入れない／あごは太く短く・先だけ色を変える／顔の中は色のかたまりで分ける（額・ほお・口の上の板）・1つの顔に3〜4色／口に見える線は入れない**。形・色・模様は自分のもの（お手本の顔は写さない）
- 9回目（作り手「魅力がない。触角の位置がおかしい。頭のヘルメットが変。デザインに意図が感じられない」）：8回目は、やり方をチェック表のように全部入れただけだった。`mode:'face2'`（`antFace2`）。**決まり：描く前に ①見どころ（主役）を1つ決める ②ほかの部品は主役より目立たせない（太さ・色）③色のかたまりは体の実際の部分か光のどちらかを表す（体に無い色分けを置かない）④見た目の都合で体のつくりを曲げない（触角は顔から生える）⑤目立つ色は主役にだけ使う**。失敗の記録：顔のまん中の暗い丸は目・鼻に見える／太い線を輪にすると鼻輪に見える（あごは刃の形にする）
- 10回目（作り手「光の線をむやみに入れない。部分塗りで光は足りている。目が単純。配色を分析して」）：お手本2枚の色を測った（`PIL` で色を数える）。分かったこと：暗い色に黒が無く背景の色みに寄せた濃い紫／明るいほど黄色へ・暗いほど紫へ色みをずらす／どの色もあざやか（S 65〜90）／広い色は2つ＋反対の色みはごく小さく（1%未満）／暖色は明るく寒色は暗く使う。決まりは `antFace2` の上に記録
