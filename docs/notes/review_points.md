# 指摘帳（見直しループの点検項目）

作り手がこれまでに出した指摘を、次から自分で見つけるための点検項目にしたもの。**作り手が新しい指摘を出したら、その場でここに1行足す**（どの動画の・いつの指摘かも書く）。
見る役（別の Claude）は `tools/REVIEW.md` の手順で、この表の全部を、渡された一覧の画像に当てる。

## B：見れば分かる乱れ（重い。見つけたら必ず直す）
- B1 体の部品が離れている：耳・あし・頭・目の上の線などが、体から浮いている（2026-11-22 緑のアラビア）
- B2 下地の形が見えている：水ぎわが階段のように段々／口の中に四角い板／切り抜きのふちがまっすぐ（同）
- B3 頭の重なり：生き物の頭が、ほかの生き物の頭に重なって「頭が2つ」に見える。主役2つのあいだに、半分かくれた物がある（同）
- B4 理由のない白い線・点：水や空に、短い白い線や点が散ってちらつく（同）
- B5 前のコマの絵が残る・色の線がにじむ（同）
- B6 使い回し：同じ形が3つ以上並ぶ（生き物・木・草・雲・骨）。1つずつ大きさ・形・色・向きを変える（同）
- B7 顔つきの不ぞろい：同じ種類なのに、目の光・まゆ・色が場面や向きでちがう。黒い点だけの目（虫のように見える）（同）
- B8 奥がからっぽ：手前にだけ物があって、奥に続いていない（草むらなのに奥に草がない）（同）
- B9 薄い色の物が重なって、透けた幽霊のように見える（同）
- B10 鼻の穴・もようが目に見えて、1頭に顔が2つあるように見える（斜め前から見たカバ。見直しループ3周目で見つかった・2026-11-22）
- B12 接する所の隙間・めりこみ：体と水面・地面の境目に隙間がある（体が浮いて見える）か、めりこんでいる。しぐさ（あくび・頭を上げる・跳ねる）の**いちばん大きい瞬間**で必ず見る。水に入った体は水面でまっすぐ切れて見えるのが正しい（緑のアラビア：あくびで下あごを底に体が浮き上がり、水面とのあいだに隙間ができていた。作り手・2026-11-22）
- B11 ぼかした手前の物の上に、くっきりした線・点が乗っている（奥の物のはずの線が、手前より前にある）（同）

## M：動き（連続コマと report.txt の数字で見る）
- M1 近づいているのに、物が動かない・大きくならない（同）
- M2 じっとしている物から、波・輪・線が出続ける。水の動きは、動いたときだけ（同）
- M3 ちらつき：細かい物が大量にばらばらに動いて落ち着かない。report.txt の「ちらつきの疑い」を必ず見る（同）
- M4 別々に動くはずの物が、同じ動きをする（主役が跳ねると、まわりの魚も一緒に跳ねる）（同）
- M5 止まった画面で待つ：語りのない所で、絵が止まっている（2026-11-17 の決まり）。report.txt の「止まっている疑い」を見る
- M6 向きを無視した変化：変身・崩れるときに、もとの向きを引きつがない（全員が横向きの骨になる）（同）
- M7 生き物の動き方が実物とちがう（水中のカバは、4本のあしをばたばた動かさない。けって、のびて、すべる）（同）

## F：事実（描いた物が、実物・文献に合っているか）
- F1 描く前に、実物の映像と文献を見たか。見ていない物（色・深さ・動き方・まわりの生き物・草木）があれば差し戻す（同。「実物や他の人を学ぶとよくなる」）
- F2 絵の描き方も、うまい人の絵（kurzgesagt など）を見てから描いたか。草・木・雲・背景の重ね方（同）
- F3 確かめていない所は「要確認」と報告に書いてあるか

## T：好み（作り手がこれまでに言ったこと。当てはまりそうなら「判断してほしい所」に入れる。勝手に大きく変えない）
- T1 情報が多すぎない：主役と景色。脇役（鳥・ほかの動物）を足しすぎない（同）
- T2 場面が長すぎない：入りの景色は3秒ほどで足りた（同）
- T3 草・木・雲は「大きな面＋まばらな株＋層」。細い物をびっしり並べない。雲は大きく・うすく・ななめに流れ、ふちがやわらかい（同）
- T4 奥の景色は層に分ける：遠いほど小さく・うすく・青く。こういう細かい所で差が出る（同）
- T5 構図を変える：横だけでなく、斜め・正面・真上・水中。全員が同じ向きにならない（同）
- T6 遊び心：突然の変化は一気に（骨になる瞬間に、まわりも砂漠に）（同）
- T7 生き物はキャラクターに寄せすぎない。リアルさと可愛さの両方（同）
- T8 手前をぼかして奥を見せる入り方が好み（同）
