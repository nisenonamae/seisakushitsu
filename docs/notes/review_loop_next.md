## 作る物
1. **実物帳**：場面の種類ごと（生き物・水・草原…）に、実物の映像のコマを保存する場所。見る役に「実物のコマ」と「作った絵のコマ」を並べて渡し、違いを挙げさせる（①）
2. **手本帳**：kurzgesagt の動画をこま送りで見て、似た場面（草原・水辺・水中・群れ・空と雲・切り替え）のコマと、そこから読み取った「やり方」を言葉で貯める。見る役に「手本にあって、こちらにない物」を挙げさせる（②）。**絵をそのまま写さない。写すのは考え方**（層の重ね方・色の決め方・動きの付け方）
3. **2案を並べて選ぶ**：改善は1つずつ。前の版と新しい版を並べ、別の見る役に「どちらが手本に近いか」を選ばせる。負けたら戻す
4. **1周で見る段は1つ**（段0〜6 に合わせる）
5. **好みを貯める**：指摘帳の T と、作り手が「いい」と言った版のコマを見る役に渡す
6. 見る役に、調べた記録（文献・映像で確かめたこと）も渡す（今は画像だけなので、事実の点検ができなかった）
