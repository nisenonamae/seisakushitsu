# 構図（絵を作る前に読む）

2026-11-21。作り手「アニメで勝負している俺らは、構図で勝たないといけない」。構図の解説2本（ポイント帳の札「構図」16件）と、作り手が見せてくれた18の型から。

## 描く前に決めること（この順で）
1. **この場面は「物の話」か「場所の話」か**：物の話＝寄って低く・主役だけ鮮やかに／場所の話＝引いて高く
2. **主役を1つ**書く。支える物は2つまで（目を引く所は多くて3つ）
3. **型を1つ選ぶ**（下の表）。主役を型の「主役を置く所」に置く。まん中に置くのは、理由が言えるときだけ（カメラの目線の点など）
4. **目の道**を線で決める：入口（手前の暗い物・道）→ 主役 → 支える物 → 主役へ戻る。目が画面の外へ出ていかないこと
5. **空ける所**を決める：描きこむ所と空ける所を先に分ける。主役のまわりは空ける。空きすぎたら小さな物を1つ
6. **光が当たる所**を決め、主役をそこに置く。ほかは影に入れて、暗く・くすませる。主役より明るい広い面を置かない
7. **斜めの線**を1本は入れる（正面・真横だけの絵は止まって見える）。見上げる・見下ろすも試す
8. **釣り合い**：大きな物を片側に置いたら、反対側に空きか小さな物。端ぎりぎりに物を置かない
9. **数は奇数**：2つ並べない（張り合う）。3つにするか、大きさで主従をつける
10. **くり返しと変化**：形の型はそろえ（まとまり）、大きさ・傾き・色みは1つずつ変える（同じ物を2回置かない）
11. **ふちとふちを接しさせない**：はっきり重ねるか、はっきり離す。主役の色は、すぐ後ろの物と変える
12. **場面をまたいでも、主役の位置を変えない**（アニメならでは。木の回の録画から）

本番の前に、**構図の小さな下絵を6つほど1枚にまとめて作り手に見せ、選んでもらってから描く**。

## 型の使い方
- 一覧の見本：`tools/vis/html/comp.html`（場面として描くと一覧の絵になる）
- 確かめ方：場面の指定に `"guide":"<型の名前>"` を足すと、補助線（赤）と主役を置く所（黄色の点）が絵の上に重なる。本番では外す
- 定義：`tools/vis/html/comp.js` の `COMP`。型を足すときはここに1行。場面のページは `<script src="comp.js">` を読みこむ

## 型の表
| 名前 | 指定 | どんなとき | うちの場面の例 |
|---|---|---|---|
| 三分割 | `thirds` | 迷ったらまずこれ。主役を交わる点のどれかに置き、地平線は上か下の線に合わせる | ふつうの説明の場面。主役を左下の点、次に見せる物を右上の点 |
| 黄金分割 | `golden` | 三分割より少しまん中寄り。落ち着いた、品のある置き方 | 主役が1つで、まわりを広く見せたい風景 |
| 黄金分割・すみ寄せ | `gcorner` | 画面を大・中・小と分けていき、いちばん小さい区切りに主役を置く。大きな面は空ける | 広い空や海の中の、小さな家や船 |
| 黄金のうずまき | `spiral` | 目を大きく回して、うずの中心（主役）へ連れていく。回り道の途中に支える物を置く | 手前の草 → 丘の線 → 木の上の家、のように順に見せたい場面 |
| 対角線 | `diagonal` | 画面を斜めに切る。動き・勢い・坂を出す。線の上か、線で分かれた広い側に主役 | 山の斜面、流れ落ちる水、坂道。止まって見える絵を動かしたいとき |
| 2本の対角線 | `xdiag` | 2本の斜めの線が交わる所に目が集まる。道や川の分かれ目・交わり | 道の交差点、川の合流、2つの流れがぶつかる所 |
| 黄金三角形 | `gtriangle` | 対角線1本と、残りのすみから下ろした線で、画面を三角に分ける。三角ごとに明暗や物を割りふる | 斜面と空と谷のように、3つの面で見せる風景 |
| ピラミッド | `pyramid` | 下が広く上がとがる三角。安定・重さ・大きさ。主役は頂点か、三角の中 | 山、大きな建物、積み上がった物。「どっしり」を見せたいとき |
| V字 | `vshape` | 左右から斜めに下りる物ではさみ、谷の底か、開いた上（空）へ目を導く | ビルの谷間、両側の木の間、谷。奥へ続く感じ |
| L字 | `lshape` | 片側に縦に長い物、下に横に長い物でわくを作り、空いた広い側に小さな物を置く | 手前の木や柱と地面でわくを作り、遠くの山や月を見せる |
| C字 | `cshape` | 枝や岩で画面を「C」の形に囲み、開いた口から奥の景色を見せる | 手前の枝ごしに見る景色。のぞきこむ感じ |
| 円 | `circle` | 主な物を輪の形に並べ、目を輪の中で回らせる。まん中の空きも絵の一部 | 池や広場を囲む景色。1つの場所にとどまって見せたいとき |
| S字 | `scurve` | 道や川をS字に曲げて、手前から奥へゆっくり目を連れていく。やさしい・のどかな印象 | 川、水路、道。奥行きを見せたい引きの画面 |
| 放射 | `radial` | たくさんの線が1点に集まる。その点がいちばん強い主役になる。奥行きと勢い | 線路や道の消える先、光の中心。カメラが前へ進む場面（目線の点） |
| トンネル | `tunnel` | 手前の暗いわくの中に、明るい出口を小さく見せる。出口に主役 | トンネル、門、窓の向こう。森のすき間の先 |
| 十字 | `cross` | 縦の物と横の線（地平線）が交わる。静か・止まった・おごそかな印象 | 1本の木と地平線。動きを止めて見せたい締めの場面 |
| 大と小 | `bigsmall` | 大きな物と、離れた小さな物。大きさの差そのものを見せる。小さいほうが目を引く | 大きさ比べ。巨木と小さな家、ダムと人 |
| 左右に同じ重さ | `pair` | 同じくらいの物を左右に置く。安定するが、動きはなくなる。比べる・対にする | AとBを並べて比べる場面。2つが張り合わないよう、色か大きさで少し差をつける |

## 型と動き（アニメで使うとき）
- 放射・トンネル・V字：カメラが前へ進む場面。集まる点を目線の点にして、動かさない
- S字・うずまき：目の道に沿って、物を順に出す（手前から奥へ）
- 対角線・2本の対角線：斜めの線に沿って物を動かす／カメラを流す
- 十字・左右に同じ重さ・ピラミッド：止めて見せる場面（締め・比べる）
- 大と小：小さいほうを後から出すと、大きさの差が伝わる

## 見た絵から足した型（作り手が構図美を感じた絵から、増やしていく）
止めた絵の解説には出てこない、動画ならではの型が多い。**足し方**：作り手が「この構図がいい」と画面の写しを送る → 何が効いているか（線・面の分け方・主役の位置）を言葉にする → `comp.js` の `COMP` に1行足す（名前・補助線・主役の位置・使いどころ・うちの例。絵そのものは写さない）→ この表に1行。

| 名前 | 指定 | どんなとき | うちの場面の例 |
|---|---|---|---|
| 格子のくり返し | `grid` | 同じ大きさのわくに、少しずつ違う物を並べる。種類の多さ・ちがいを見せる。1つだけ色や動きを変えると、そこが主役になる | 種類を並べる場面（いろいろな道、いろいろな土）。わくの形と大きさはそろえ、中身は1つずつ変える |
| 斜めの仕切りで2つ | `split` | 画面を斜めの線で2つに割り、別の世界を並べる。まっすぐ割るより動きが出る。片方を残したまま、もう片方を横から入れる | 比べる相手の差し込み（「東京はどうでしょうか」）。主役の絵を消さずに、斜めの板で入れる |
| 3枚に割る | `tri` | 例を3つ、縦長の3枚に並べる。3枚つながったまま入り、1枚が広がって次の場面になる | 例を3つ出すとき（部品 "t":"tri"） |
| 縦に長い1枚を動く | `tall` | 上下でつながる物を、切らずに1枚の縦長の絵にして、カメラが動く。層ごとに速さを変える | 木の上から根まで、雪山から蛇口まで、ダムの上から水の底まで |
| 手前の黒いわく | `frame` | いちばん手前に、黒に近い大きなかたまりを片側か両側に置き、その間から奥を見せる。光の来る側のふちだけ明るくする。左右は同じ形にしない | 森・街・洞くつ。近くから見ている実感を出したい場面 |
| はみ出すほど寄る | `closeup` | 主役を画面に収めず、大きくはみ出させる。迫力・近さ。画面に入れるのは、いちばん見せたい部分（目など）だけ | 小さな物（虫・部品・水のしずく）の話の入り。大きさを忘れさせる |
| 主役を止めて背景を変える | `hold` | 場面が替わっても、主役を画面の同じ位置・近い大きさに置く。1回の切り替えで変えるのは1つだけ（大きさ／背景の色／まわりの物） | 同じ物の話が続くあいだ。時間がたつ話は、主役を止めて空の色を変える |

### 18の型のうち、見た絵で確かめられたもの（2026-11-21。画像6枚と録画2本の範囲）
放射（光の切り替え）／V字（森の空のすき間）／トンネル・C字（森の手前のわく）／対角線（手前の枝・見上げた幹）／S字（巨木の足もとの小道）／十字・まん中（巨木が立ち続ける場面）／左右に同じ重さ（巨木とクジラ）／大と小（巨木と小さな人）。ほかは「見た中には無かった」だけで、使っていないとは言えない（要確認）。
