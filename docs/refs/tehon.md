# 手本帳（kurzgesagt から読み取った「やり方」）

見る役・選ぶ役に渡す、手本のやり方の言葉の帳面。**コマ（画像）はここに置かない**（著作物なので。見たいときは下の「足し方」で、その場で見る）。
守る線は1つだけ：**特定の絵・キャラクター・場面をそのまま写さない（丸写しをしない）**。形の作り方・色・層・動き・切り替えは、遠慮なく学んで寄せる（作り手・2026-11-22「ゴールは kurzgesagt と遜色ないクオリティ」）。

## 書き方
1項目1行：`- [番号] やり方 ／ どこで見たか（動画の題・秒。作り手の観察なら「作り手」）／ うちで使う場面`
- 番号は場面の種類の頭文字＋数字（草＝草原、水＝水辺、中＝水中、群＝群れ・生き物、空＝空と雲、切＝切り替え・カメラ、絵＝絵の作り全般）
- 「どこで見たか」が空の物は書かない。想像で足さない

## 足し方（Claude in Chrome がつながっているとき）
1. 作り手の Chrome で kurzgesagt の動画を開く（新しいタブ）
2. `document.querySelector('video').pause(); document.querySelector('video').currentTime = 秒` で止め、画面を小さく切り出して見る（音は取らない）
3. 似た場面（草原・水辺・水中・群れ・空と雲・切り替え）を1本につき 5〜10コマ見て、**言葉で**ここに足す。コマはこの作業場の `~/.cache/seisaku_refs/tehon/` に置いてよいが、リポジトリには入れない
4. 足したら、関係のある場面の作り直しの「改善の候補」に入れる

## 絵の作り全般
- [絵1] 生き物の体は、ただの円ではなく、部品を階層に分けて重ねる（腹・胸・頭を別の面にして重ね順で立体を出す）／作り手（アリの絵・2026-11-21）／カバ・骨
- [絵2] 細い部品（あし・触角）は、途中でちゃんと折れる太めの一本線／作り手（同）／骨・草の茎
- [絵3] 影は面の一部に色を上塗りする「部分色分け」で表し、一本線を足して補う。光の線をむやみに入れない／作り手（2026-11-21）／カバ・木・岩
- [絵4] 重なる部品に同じ色をかぶせない（となり合う面は必ず明るさか色を変える）／作り手（2026-11-21）／群れ・草むら
- [絵5] 図形のままにしない：顔も体も円・だ円の組み合わせが見えないよう、絶妙にくずした形にする。ゆるキャラすぎず・少しかわいく・リアル／作り手（2026-11-21）／カバの顔
- [絵6] 素材を使い回さない。同じ種類の物（木）でも1つずつ大小・形の個性を変える／作り手（森の絵・2026-11-21）／木・草の株・骨・魚
- [絵7] 大きな背景（土台）を先に置き、その上に部品を組み立てる／作り手（2026-11-21）／全部の場面

## 空と雲（空）
- [空1] 雲は丸いわた雲ではなく、大きく・うすく・ななめに流れる、ふちのやわらかい雲／作り手（2026-11-22、kurzgesagt の絵を見本に）／草むら・横からの湖

## 遠景・層（草原・水辺）
- [草1] 奥の景色は層に分け、遠いほど小さく・うすく・青く／作り手（2026-11-22）／草むら・横・正面
- [草2] 手前の物のふちに明るい所を置き「光が当たっている」を出すと、近くで見ている実感が出る（光の線ではなく部分塗り）／作り手（森の絵・2026-11-21）／手前の草・カバの背中
- [草3] 手前と奥の距離感：手前は大きく暗く・ぼかし、奥は小さく明るく／作り手（森の絵・2026-11-21）／草むら

## 切り替え・カメラ（切）
- [切1] 手前をぼかして奥を見せる入り方／作り手（2026-11-22）／序の入り
- [切2] カメラは動いていても目線が動かない（見てほしい物を画面の同じ所に置いたまま動く）。切り替えとカメラの動きを合わせる／作り手（2026-11-21）／全部の場面
- [切3] 例を出すとき画面を三分割し、それぞれにアニメ付きの例。入りは「3枚つながって端から加速して入り、なめらかに着く」か「今の画面が左の1枚になり、他の2枚が端から入る」。切り替えは右の1枚が拡大／作り手（2026-11）／第1章以降
