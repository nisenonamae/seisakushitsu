# 素材の決まり（素材を作る前に読む）

作り手・2026-11-26：kurzgesagt の動物は、部品の数は多くないが一個一個が洗練されていて、どれもどこか図形的。点の多いぼこぼこした形は「洗練されていない」に見える。

## 形
- **図形から始める**：円・長丸（太い線）・しずく・角丸の四角を置いて、少し変形する。手で囲んだような形から始めない
- **点は少なく**：1つの部品は 4〜8 点が目安（複雑な胴でも 12 点まで）。長いなめらかな曲線でつなぐ。小さなでこぼこ・揺らぎを輪郭に入れない
- **角は意図した所だけ**：しずくの先・きば・口の端など。それ以外はなめらか
- **左右対称にできる物は対称に**（尾びれ・正面の顔）

## 光・影・線
- 光・影は**別の部品を重ねる**（面の一部を別の色で上塗り。グラデーションにしない）。1つの部品は1色
- 背中の光・口・腹のすじ・しわは**線の部品**（太さ一定・両端が丸い。`{line:{pts,w}}`）。面を細く囲んで作らない
- 光は目立たない範囲で、数を絞る

## 構成
- 部品の数を増やして細かくするより、少ない部品の形を磨く
- 重なる部品に同じ色がかぶらないよう色を分ける
- 場面ごとに素材を変える（使い回しすぎない）

## 作るとき
- 描く式（`tools/kahitsu/extra_art.js` など）でも同じ：`blob` に点をたくさん並べず、少ない点＋ `NM()` で名前・親子・付け根を付ける
- できたら「部品で直す」で開いて、◇ 形で点の数を見る。多い部品は「✨ 清書する」で減らしても形が保てるか確かめる
