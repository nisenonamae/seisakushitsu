# 自動化の設計（AUTOMATION_DESIGN）

2026-11-27。**案**。

## 1. 3つの度合い

工程ごと（場面ごとに上書き可）に、次の3つから選ぶ。**いつでも変えられる。作業の途中でも。**

| 度合い | 誰が手を動かすか | AI のすること | 人のすること |
|---|---|---|---|
| **人が主導** | 人 | 頼まれたときだけ手伝う（清書・案出し・点検の結果を見せる）。自分からは文書を変えない | 作る |
| **一緒に** | AI が作り、人が方向を決める | 案を「提案」として出す。採られた物だけが文書に入る | 見て、採る・直す・断る・方向を言う |
| **AI が主導** | AI | 許された範囲で文書を直接変える。自分で見直す。区切りごとに報告 | あとから見る。いつでも止める・戻す・自分で直す |

3つは**同じ文書・同じ命令・同じ画面**の上で動く。違うのは「AI の命令が、すぐ文書に入るか（AI が主導）、提案として待つか（一緒に）、出せないか（人が主導）」だけ。だから切りかえても、やり直しや移し替えは起きない。

### 切りかえの決まり
- 「AI が主導」の途中で人が同じ所を触ったら、その部品・場面は自動で「一緒に」に落ちる（人の手が優先）。AI は続きを提案として出す。
- 「AI が主導」→「人が主導」に変えたら、進行中の AI の作業は区切りで止まり、やりかけは提案として残る（消さない）。
- 度合いの変更も記録に残る。

## 2. 許可

度合いとは別に、「AI に何を許すか」を持つ。度合いは「どう進めるか」、許可は「どこまで触ってよいか」。

```
Perms = {
  read:   すべて（いつも許す）
  write:  { 語り / 絵の形 / 色 / リグ / 動き / カメラ / 音 / 素材の棚 / 決まり } それぞれ 可・提案のみ・不可
  create: 新しい部品・場面・素材を作ってよいか
  delete: 消してよいか（既定：不可。消したい物は「消す提案」にする）
  external: 外へ出る動作（書き出しの実行・push・公開）それぞれ 可・聞く・不可
  budget: 見直しの周の上限・1回の作業で変えてよい量
}
```

**どの度合いでも変わらない決まり（固い守り）**
1. **固定された物は変えない**。`frozen` は変更不可。`ask` は必ず提案にする。作り手が「良い」と言った物は固定する（今の決まり「良いと言われた物は固定して1か所ずつ直す」を仕組みにする）。
2. **前の段を作り替えない**。動きの段で形を変える、のような変更は提案にしかできない（今の「段を分けて作る」）。
3. **消す・公開する・外へ送る**は、AI が主導でも人の承認が要る。
4. **決まり（rules）と指摘帳は、AI は足す提案しかできない**。書きかえ・削除は人。
5. **AI は命令しか使えない**。ファイルを直接書きかえない。人の画面でできないことは AI にもできない。
6. **取り消せない操作は、度合いに関係なく人が決める**。

## 3. 提案と承認（「一緒に」の中身）

1. AI は、いまの文書を土台に、命令のまとまり（提案）を作る。文書はまだ変わらない。
2. 提案には必ず付ける：**何を・なぜ**（1〜2文）／**見本**（前と後を並べた画像か短い動画）／**機械の点検の結果**／どの決まり・どの指摘に基づくか。
3. 人の画面には「前／後」を重ねて見せる。人は：
   - **採る**（全部）／**一部だけ採る**（部品ごと・命令のまとまりごとに選ぶ）／**直してから採る**（採ってから自分で触る）／**断る**（理由をひとこと。理由は指摘帳の候補になる）／**方向を言う**（「もっと丸く」→ AI が出し直す）。
4. 提案の土台が古くなったら（人が先に同じ所を直した）、`stale` にして、AI が新しい土台で出し直す。古い提案を無理に当てない。
5. 案が複数あるときは並べて出す（今の A/B・「2案並べて選ぶ」と同じ）。

**提案の大きさ**：作り手の決まり「細部は1つ1つ」に合わせ、既定は小さく（1つの部品・1つの動き）。「まとめて」と言われたときだけ大きくする。

## 4. AI が主導のときの流れ

今の「見直しループ／見直しのサイクル」を、そのまま仕組みの中身にする。

```
作る係 → 機械の点検 → 見る係（作る所を見ていない別の AI）→ 直す → …（上限 N 周）
                                   ↓ 良くなったか分からない変更
                             前の版と2案を並べ、別の AI が選ぶ。負けたら戻す
```

- 作る係と見る係を分ける（自分の仕事を自分で採点しない）。
- 順番は今のとおり：**ミスを直す → より自然に（実物帳と比べる）→ もっと良くする挑戦（手本帳と比べる）**。挑戦が2回続けて負けたら止める。
- 区切り（段が1つ終わる・上限に達する・迷う点が出る）で止まり、報告する：何をしたか／前と後／迷った所／次にしたいこと。
- **迷ったら止まる**：決まりどうしがぶつかる・固定に当たる・取り消せない・質が下がったかもしれない、のときは進めずに聞く。
- 人がいない間も進めてよいのは、許可の範囲の中だけ。

## 5. 人の割りこみ

| したいこと | できること |
|---|---|
| 今すぐ止める | 「止める」で、AI の作業は命令の区切りで止まる。途中の変更は残り、1つずつ見られる |
| 自分で直す | いつでも、どの度合いでも直せる。人が触った所は人の物（1節の切りかえの決まり）|
| ここは触るな | 部品・場面・値を固定する |
| 方向を変える | ひとこと指示を書く。AI は次の区切りから従う |
| 任せ方を変える | 度合い・許可を変える |

AI が主導であることは、人の割りこみを妨げる理由にならない。画面は常に人が操作できる。

## 6. 取り消しと巻き戻し

すべての変更は命令として記録される（DATA_MODEL.md 9節）。だから：

- **1つ戻す**：ふつうの取り消し（人の変更も AI の変更も同じ）。
- **この作業だけ戻す**：AI の1回の作業（命令のまとまり）を選んで戻す。そのあとの人の変更は残す。ぶつかる所があれば見せて選ばせる。
- **この時点まで戻す**：場面・素材を、ある時点の状態に戻す（「昨日の夜の版」）。戻す前の状態も残る（戻したこと自体を取り消せる）。
- **見比べる**：2つの時点を並べて見る・重ねて見る。
- **合格の印**：作り手が「OK」と言った時点に名前を付けて残す。いつでもそこへ戻れる。

記録は足すだけで、消さない。巻き戻しも「逆向きの命令を足す」。

## 7. AI をどう動かすか

| 方法 | 中身 | 今すぐ | 費用・鍵 |
|---|---|---|---|
| 会話で頼む | 今と同じ。人が Claude の会話を開いて頼む | できる | 今のまま |
| 予約タスク | 決まった時刻に、待っている作業を片づける | できる（種の泉で実績あり）| 今のまま |
| アプリから直接 | 画面のボタンから API を呼ぶ | 新しい鍵と費用が要る | 作り手の約束（新しいトークンを作らせない）に反する。今は採らない |

**おすすめ**：上の2つを「作業係」として整える。画面が「作業の札」（どの工程・どの場面・何をしてほしいか・度合い・許可）を文書に書き、作業係がそれを読んで命令か提案を書き戻す。今の `jobs` と `WORKER.md` の発展形。作業係の中身は差しかえられるようにしておく（将来アプリから直接呼ぶ形に変えられる）。

- 作業係が読む物を小さくする：今の `rules_for.py` と同じく、**その作業に要る決まりだけ**を渡す（トークンの節約）。
- 作業係は、文書の核（①）を自分の環境で動かして、命令を当て、下見の画像を作り、点検を流す。人の画面と同じ結果になる（評価⑤が純粋な計算だから）。

## 8. 工程ごとの既定（案）

作り手のこれまでの言葉から置いた初めの値。どれもいつでも変えられる。

| 工程 | 既定 | 理由 |
|---|---|---|
| 題材の候補・調べ | AI が主導 | 今も自動。最後に選ぶのは人 |
| 構成・肉付け | 一緒に | 「構成は案から良い所を残し、いらない所を削る」|
| 絵コンテ（場面の設計） | 一緒に（つかみと山場は人が主導）| 「場面がいちばん大事」「自分の手をかなり交える」|
| 素材（絵） | 一緒に | 「細部は1つ1つ指示する」。図形から AI が組み、人が整える |
| リグ | AI が主導 | 手間のわりに判断が少ない。見て直せる |
| 動き（大） | 一緒に | 動きの質が一番難しい、と作り手が見ている |
| 動き（小：揺れ・呼吸・まばたき） | AI が主導 | 式と部品で付ける。量が多い |
| カメラ・つなぎ | 一緒に | 「カメラにも自分で手を加えたい」|
| 音 | 人が主導 → 学んだら AI へ | 「自分で置き、それを学習させる」|
| 題名・サムネ | 一緒に（サムネは人が描く方向）| |
| 点検・書き出し | AI が主導（公開は人）| |

## 9. 記録に残すこと
- だれが（人／どの作業係）・いつ・何を・なぜ（提案の理由）・どの決まりに基づいて。
- 断られた提案と理由。→ 次の作業に効かせる（指摘帳の候補）。
- 度合いと許可の変更。
- これらは「この動画は誰がどこまで作ったか」をあとで見返す材料にもなる。

## 10. まだ決めていないこと
- 「一部だけ採る」の単位（部品ごと／値ごと）の見せ方。
- 作業係が動いている間の、人の画面への知らせ方（今は通知の仕組みが無い）。
- AI が主導で長く動かしたときのトークンの量（1場面あたり）。試して測る。
